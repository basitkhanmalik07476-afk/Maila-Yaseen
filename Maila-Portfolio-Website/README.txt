MAILA PORTFOLIO WEBSITE
=======================

Folder structure
  index.html            the page (all text and sections)
  css/style.css         all design, colours, light and dark theme
  js/main.js            animations, menu, FAQ, form, WhatsApp links
  images/maila-portrait.jpg   hero photo
  images/favicon.svg    browser tab icon

How to open
  Double-click index.html. It works in any browser.
  Internet is needed for the Google fonts (Bricolage Grotesque, Figtree, DM Mono).
  Offline, the site still works but shows a similar fallback font.

How to publish (free options)
  - Netlify: go to app.netlify.com/drop and drag this whole folder in.
  - Vercel or GitHub Pages: upload the folder contents.
  - Normal hosting (cPanel): upload everything into public_html, keeping the folders.
